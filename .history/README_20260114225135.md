# 🚛 Optimización de Rutas de Reparto en Trujillo con Algoritmos Genéticos

Aplicación web premium para la optimización inteligente de rutas de reparto en la ciudad de Trujillo utilizando algoritmos genéticos avanzados. Diseñada con una interfaz moderna, visualizaciones diferenciadas y funcionalidades de vanguardia.

## ✨ Características Destacadas

### 🎨 **Interfaz Visual Premium**
- **Puntos de entrega totalmente diferenciados**: Cada distrito tiene colores únicos, íconos personalizados y tamaños dinámicos según demanda
- **Animaciones avanzadas**: Transiciones suaves, efectos hover, micro-interacciones y animaciones de rutas
- **Tema dinámico**: Toggle entre modo claro y oscuro con transiciones elegantes
- **Diseño responsive**: Optimizado para desktop, tablet y móvil

### 🗺️ **Visualización Interactiva Avanzada**
- **Mapas múltiples estilos**: Streets, Satellite, Dark y Light modes
- **Rutas animadas**: Visualización progresiva del dibujo de rutas optimizadas
- **Tooltips inteligentes**: Información contextual rica al pasar el mouse
- **Clusters automáticos**: Agrupación inteligente de puntos cercanos

### 🧬 **Algoritmos Genéticos Optimizados**
- **Selección por torneo**: Método robusto para selección de padres
- **Cruzas avanzadas**: Order Crossover (OX) y Partially Mapped Crossover (PMX)
- **Mutaciones inteligentes**: Swap e inversión para diversidad genética
- **Elitismo configurable**: Preservación de mejores soluciones

### 📊 **Métricas y Analytics en Tiempo Real**
- **Dashboard dinámico**: KPIs con animaciones escalonadas
- **Gráficos interactivos**: Evolución del fitness con zoom y pan
- **Métricas múltiples**: Distancia, tiempo, fitness, diversidad poblacional
- **Exportación avanzada**: Resultados en múltiples formatos

### ⚙️ **Controles Avanzados**
- **Parámetros configurables**: Población, generaciones, probabilidades de cruza/mutación
- **Generación de datos**: Sistema inteligente de creación de datasets simulados
- **Control de ejecución**: Iniciar, pausar, reiniciar con feedback visual
- **Validación en tiempo real**: Verificación automática de parámetros

## 🏗 Estructura del Proyecto

```
.
├── app/                    # Código de la aplicación web
│   ├── assets/            # Archivos estáticos (CSS, imágenes)
│   ├── callbacks/         # Lógica de los callbacks de Dash
│   ├── components/        # Componentes reutilizables
│   └── layouts/           # Diseños de la interfaz
├── data/                  # Datos de entrada (se generan automáticamente)
├── resultados/            # Resultados de las optimizaciones
├── src/                   # Código fuente del algoritmo genético
│   ├── algoritmo_genetico.py
│   ├── funciones_fitness.py
│   ├── generador_datos.py
│   ├── operadores_geneticos.py
│   └── utils.py
├── tests/                 # Pruebas unitarias
├── config.py              # Configuración global
├── main.py                # Punto de entrada
└── requirements.txt       # Dependencias
```
