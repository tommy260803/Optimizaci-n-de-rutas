# 🚛 Optimización de Rutas de Reparto en Trujillo con Algoritmos Genéticos

Aplicación web premium para la optimización inteligente de rutas de reparto en la ciudad de Trujillo utilizando algoritmos genéticos avanzados. Diseñada con una interfaz moderna, visualizaciones diferenciadas y funcionalidades de vanguardia.

## ✨ Características Destacadas

### 🎨 **Interfaz Visual Premium**
- **Puntos de entrega totalmente diferenciados**: Cada distrito tiene colores únicos, íconos personalizados y tamaños dinámicos según demanda
- **Animaciones avanzadas**: Transiciones suaves, efectos hover, micro-interacciones y animaciones de rutas
- **Tema dinámico**: Toggle entre modo claro y oscuro con transiciones elegantes
- **Diseño responsive**: Optimizado para desktop, tablet y móvil

### 🗺️ **Visualización Interactiva Avanzada**
- **Mapas múltiples estilos**: Streets, Satellite, Dark y Light modes
- **Rutas animadas**: Visualización progresiva del dibujo de rutas optimizadas
- **Tooltips inteligentes**: Información contextual rica al pasar el mouse
- **Clusters automáticos**: Agrupación inteligente de puntos cercanos

### 🧬 **Algoritmos Genéticos Optimizados**
- **Selección por torneo**: Método robusto para selección de padres
- **Cruzas avanzadas**: Order Crossover (OX) y Partially Mapped Crossover (PMX)
- **Mutaciones inteligentes**: Swap e inversión para diversidad genética
- **Elitismo configurable**: Preservación de mejores soluciones

### 📊 **Métricas y Analytics en Tiempo Real**
- **Dashboard dinámico**: KPIs con animaciones escalonadas
- **Gráficos interactivos**: Evolución del fitness con zoom y pan
- **Métricas múltiples**: Distancia, tiempo, fitness, diversidad poblacional
- **Exportación avanzada**: Resultados en múltiples formatos

### ⚙️ **Controles Avanzados**
- **Parámetros configurables**: Población, generaciones, probabilidades de cruza/mutación
- **Generación de datos**: Sistema inteligente de creación de datasets simulados
- **Control de ejecución**: Iniciar, pausar, reiniciar con feedback visual
- **Validación en tiempo real**: Verificación automática de parámetros

## 📋 Requisitos

- Python 3.7 o superior
- pip (gestor de paquetes de Python)

## 🛠 Instalación

1. Clona el repositorio:
   ```bash
   git clone [URL_DEL_REPOSITORIO]
   cd ruta-al-repositorio
   ```

2. Crea un entorno virtual (recomendado):
   ```bash
   python -m venv venv
   source venv/bin/activate  # En Windows: venv\Scripts\activate
   ```

3. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

## 🚦 Ejecución

### Desarrollo Local

1. Inicia la aplicación:
   ```bash
   python main.py
   ```

2. Abre tu navegador y ve a:
   ```
   http://127.0.0.1:8050
   ```

### Despliegue en Render

Esta aplicación está preparada para desplegarse en [Render](https://render.com), una plataforma de cloud computing.

#### Opción 1: Despliegue Automático con render.yaml

1. **Conecta tu repositorio de GitHub a Render**
   - Ve a [dashboard.render.com](https://dashboard.render.com)
   - Haz clic en "New +" y selecciona "Blueprint"
   - Conecta tu repositorio de GitHub

2. **Render detectará automáticamente el archivo `render.yaml`** y configurará el servicio

3. **Configura las variables de entorno** (opcional):
   - `DEBUG`: `false` (para producción)
   - `PORT`: Render lo asigna automáticamente

#### Opción 2: Despliegue Manual

1. **Crea un nuevo servicio web en Render**
   - Ve a [dashboard.render.com](https://dashboard.render.com)
   - Haz clic en "New +" y selecciona "Web Service"
   - Conecta tu repositorio de GitHub

2. **Configura el servicio**:
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn --bind 0.0.0.0:$PORT app.app:app`

3. **Variables de entorno**:
   - `DEBUG`: `false`
   - `PYTHON_VERSION`: `3.11.7` (versión recomendada)

4. **Haz clic en "Create Web Service"**

#### Verificación del Despliegue

Una vez desplegado, Render te proporcionará una URL donde podrás acceder a tu aplicación. La aplicación verificará automáticamente la estructura de directorios y generará los datos iniciales necesarios.

#### Notas Importantes

- El primer despliegue puede tomar varios minutos debido a la instalación de dependencias
- Render asigna automáticamente el puerto a través de la variable `$PORT`
- Los archivos en `/tmp` son efímeros; usa `/opt/render/project` para datos persistentes si es necesario
- Para debugging, puedes revisar los logs en el dashboard de Render
